# Custom 18-Cell Fast-Charging Power Bank 🔋⚡

A high-capacity, custom-built portable power bank engineered from scratch using 18 lithium-ion cells, cell-balancing wiring, and a high-efficiency 22.5W PD/QC module, housed in a custom sunboard enclosure.

## 🛠️ Components & Engineering Details
* **Cell Configuration:** Built using 18 lithium-ion cells connected in a robust parallel-series arrangement for massive energy storage.
* **Charging Module:** Integrated a **22.5W Power Delivery (PD) & Quick Charge (QC)** PCB module for fast input/output charging speeds.
* **Cell Balancing:** Implemented meticulous cell-balancing wiring to ensure equal voltage distribution, safety, and longevity across all cells.
* **Enclosure:** Crafted a sturdy, custom-cut **Sunboard** casing to tightly pack the heavy cell arrangement and insulate the electronics securely.

## 🎯 Project Objective
This project demonstrates practical skills in multi-cell battery architecture, high-wattage power management modules, and custom DIY hardware enclosure design.
